# LoiLoNote Local Reader

無料のChrome拡張として、ログイン済みのロイロノート画面から**現在表示されているページ**のテキスト・同一オリジンリンク・可視コントロール名をJSONに保存する試作品です。

## 現在の範囲（v0.1.0）

- 資料箱のフォルダ一覧ページを開いた状態で、表示テキストとリンク候補をローカルJSONに保存
- 資料一覧ページでも同様に保存
- 資料本文を表示したページでも、DOM上の可視テキストを保存
- Cookie、パスワード、認証トークン、非表示アプリ状態を読み取らない
- 外部サーバーへの通信・アップロードを行わない

**まだ全フォルダ・全資料を自動巡回しません。** v0.1.0は、実際のDOMでリンク構造と本文抽出可能範囲を確認するための安全な読み取りPoCです。画像・手書き・添付ファイル・数式の完全取得も未検証です。

## インストール（Chrome）

1. このフォルダをPCにダウンロードし、ZIPなら展開する。
2. Chromeで `chrome://extensions` を開く。
3. 右上の「デベロッパーモード」を有効にする。
4. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
5. この `extension` フォルダを選択する。
6. ロイロノートに通常どおりログインし、資料箱のページを表示する。
7. 拡張機能アイコンから「このページを取得」を押し、JSONを保存する。

## 次の開発段階

1. 実ページのJSONで、フォルダリンク・資料リンクがどのDOM要素に存在するか検証する。
2. 同一オリジン内の通常の画面遷移だけを使う巡回を実装する。
3. 取得漏れ・重複・巡回停止・差分同期をテストする。
4. 画像・添付ファイル・OCRは別段階で追加する。

## セキュリティ

- GitHubには拡張機能のコードのみを置く。学校資料・取得JSON・画像・個人情報はコミットしない。
- ログイン情報やCookieを入力・保存・転送しない。
- ロイロノートの通常画面でユーザーが閲覧できる情報だけを対象とする。
- アクセス制限、認証、CAPTCHA、学校の利用規則を回避しない。
- 取得した教材は本人の学習目的の範囲で扱い、公開しない。
