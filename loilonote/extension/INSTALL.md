# LoiLoNote Local Reader v0.8.1

## 目的
LoiLoNoteでユーザーが表示しているページを、可視DOM情報と画面画像としてローカル保存するChrome拡張機能です。

## インストール
1. GitHubからこのフォルダ `loilonote/extension` をZIPでダウンロードして展開する。
2. Chromeで `chrome://extensions` を開く。
3. 右上の「デベロッパーモード」をONにする。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開した `extension` フォルダを選ぶ。
5. LoiLoNoteの資料箱を開き、全教科を対象にする場合は教科一覧ページから開始する。
6. 拡張機能アイコンの「フォルダ構成を自動巡回」を押す。巡回は最大150ページ・深さ16で、検索欄より上の階層表示アイコンを画面座標で除外し、検索欄の一意性を確認する。一覧内の未識別アイコン、検索欄の複数検出、クリック直前の対象変化があれば停止する。
7. 巡回JSONの完了状態・警告を確認する。教材本文の一括取得ではない点に注意する。
8. 必要に応じて「このページを取得・保存」で表示中ページの詳細を保存する。
9. 保存先ダイアログでJSONと画面PNGを保存する。
10. 複数ページを保存した後、「保存済み全ページの索引を出力」でローカル索引を出力する。
11. 「資料検索画面を開く」で archive.html を起動し、個別JSONまたは統合索引JSONを読み込んで検索する。

## 公式エクスポート（原本保存の推奨）
画面のDOM取得だけではカードの手書き・数式・添付ファイル等を完全保存できる保証がありません。重要なノート・資料は、LoiLoNote公式のエクスポート機能も併用してください。

- ノート：授業を開き、ノート一覧右上のメニューから「エクスポート」を選び、対象ノートを選択して保存します。公式形式は `.loilonote` です。
- 資料箱：マイフォルダ右上のメニューから「エクスポート」を選び保存します。公式形式は `.loilomaterials` です。
- 公式ヘルプ上、資料箱のインポート／エクスポート対象はマイフォルダです。授業共有等の他フォルダには同じ手順を適用できるとは限りません。
- エクスポートファイルはダウンロード直後に内容を直接確認できない形式です。原本として保管し、拡張機能のJSON抽出データと混同しないでください。
- 共有ノート・提出箱・タイムラインについては、公式ヘルプで示される権限と表示範囲を尊重し、アクセス可能な範囲のみを保存します。

## 保存内容
- ページタイトル・URL・取得時刻
- 表示中画面の種別（資料箱／ノート／共有ノート／提出箱／タイムライン）。URLの `tab` パラメータは分類にだけ使用し、保存URLには含めません。
- 画面上で確認できた4区分のナビゲーション名と、現在の教科コンテキスト候補
- 表示中の本文テキスト、見出し
- 可視リンク・操作候補の属性情報と簡易DOM構造診断（操作はしない）
- 同一オリジンのorigin+pathnameのみ（クエリ・フラグメント・外部URLは除外）
- 画像のalt/URL/寸法、Canvasの寸法
- 表示中画面のスクリーンショット（現在の表示範囲のみ）
- URLごとの直近5回分の変更履歴とSHA-256指紋
- JSONを読み込んで資料名・URL・本文を検索するローカル資料検索画面（chrome.storage.local）

## 制限
- v0.8.1の画面種別分類はURLの `tab` 値（standardNoteList / sharedNoteList / submitBox / timeline）と資料箱パスに基づく補助メタデータです。各タブの全件巡回や自動切替を実装したものではありません。
- フォルダ構成巡回は初期実装で、実際のLoiLoNote上での動作検証は未実施です。検索欄より上の階層表示アイコンを画面座標で除外します。検索欄が一意に見つからない場合、一覧内に未識別アイコンがある場合、クリック直前に対象ラベル・URLが変化した場合は誤巡回を避けるため停止します。
- フォルダ一覧ページの巡回のみで、個々の教材本文・画像・添付ファイルを自動取得しません。
- 全教科を巡回するには、資料箱の教科一覧ページから開始する必要があります。
- スクリーンショットは表示範囲のみで、長いページ全体ではありません。
- 数式、手書き、画像内文字、Canvas、添付ファイル本文は完全抽出を保証しません。
- 巡回はユーザーがChrome上で開始する必要があります。Macが閉じていても自動取得する機能はありません。
- 学校アカウントの利用規則・学校の許可に従ってください。

## 安全性
- Cookie、認証情報、非表示アプリ状態を取得しません。
- 自動クリックは、ユーザーが巡回を開始した場合のフォルダアイコン候補に限定します。送信、提出、共有、編集、削除は行いません。
- 外部サーバーへデータ送信しません。保存はChromeローカルストレージとユーザーが選んだダウンロード先のみです。
- 取得データには学校資料等の個人情報が含まれる可能性があります。GitHubなど公開場所へアップロードしないでください。
