# LoiLoNote Local Reader v0.8.10

この拡張機能は、ユーザーがLoiLoNoteで現在表示しているページをローカル保存する補助ツールです。

## 主な機能
- 授業名の画面内完全一致と通常授業の明示確認を必須とする制限付きフォルダ構成巡回（最大150ページ・深さ16、フォルダアイコン候補のみ）
- 巡回結果をフォルダマップJSONとして保存し、警告・未完了状態を明示
- 検索欄より上の階層表示アイコンを画面座標で除外し、検索欄の一意性・フォルダ候補・未識別アイコン・座標・srcを診断情報として記録。未識別アイコン、検索欄の複数検出、クリック直前の一覧変化があれば停止
- 授業一覧画面の候補インベントリ。『自主学習と並行した授業』と『自主学習』自体は対象外、それ以外も通常授業と確認できない限り『判定保留』として巡回しない
- 可視ページ本文・見出し・リンク・画像情報・Canvas寸法のJSON保存
- URLの `tab` 値に基づく画面種別メタデータ（ノート／共有ノート／提出箱／タイムライン）。クエリ値そのものは保存しない
- 表示中画面のPNG保存（表示範囲のみ）
- 同一オリジンのURLをorigin+pathnameに正規化し、クエリ・フラグメント・外部URLを保存対象から除外
- URL単位のSHA-256比較による変更検出
- ローカルJSONを読み込む検索・閲覧画面（資料名・URL・本文検索）
- 複数JSONの統合索引出力
- Chromeローカルストレージに直近5版を保持
- 保存済みページ索引のJSON出力
- 文字化け・置換文字・Canvas表示の取得品質警告

## インストール
詳しくは [INSTALL.md](INSTALL.md) を参照してください。資料検索画面は拡張機能ポップアップの「資料検索画面を開く」から起動できます。

- DOM診断情報（可視操作候補の属性・タグ構造）を保存し、次段階の巡回実装に利用
- 保存URLは同一オリジンのパスのみ。クエリ・フラグメント・外部URLは除外

## 重要な制約
- v0.8.10の画面種別分類は補助メタデータのみであり、各タブの自動巡回・教科間巡回を実装したものではありません。
- フォルダ巡回はSPAのURL遷移とフォルダアイコンDOMを前提にした初期実装です。検索欄より上の階層表示アイコンは画面座標で巡回対象から除外します。検索欄が一意に見つからない場合、一覧内に未識別アイコンがある場合、またはクリック直前に対象ラベル・URLが変化した場合は停止します。実機で未検証のため、初回は小さな範囲で試してください。遷移を確認できない場合は停止します。
- 巡回対象はフォルダ構成ページのみです。個々の教材を開いて本文・画像・添付ファイルを一括取得する機能ではありません。
- 開始位置より上位の教科一覧へ自動で戻る機能はありません。全教科を対象にする場合は、資料箱の教科一覧ページから開始してください。
- v0.8.10は表示中ページの手動取得に加え、ユーザーが開始した制限付きフォルダ構成巡回に対応します。全教科・全資料本文の自動取得や毎日20時の自動起動は未実装です。
- 数式・画像内文字・手書き・Canvas・添付ファイルの完全抽出は保証しません。
- Chromeのローカルストレージには容量上限があります。JSON/PNGはダウンロード先にも保存してください。
- 学校アカウントの利用規則・学校の許可に従ってください。

## プライバシー
Cookie、認証情報、非表示アプリ状態は取得しません。フォルダ巡回ではユーザー開始後にフォルダ候補のみクリックします。送信・提出・共有・編集・削除は行いません。データの外部送信はしません。取得した学校資料はGitHub等の公開場所にアップロードしないでください。


## 授業の対象範囲（v0.8.10）
- 対象は通常授業のみです。「自主学習と並行した授業」と可視表示から確認できた授業は対象外とし、ページ取得・資料箱巡回を停止します。
- 授業一覧の候補は、明示的な除外表示を検出した場合のみ「対象外」と記録し、候補ごとの表示コンテキストも診断JSONに残します。「自主学習」項目の存在も別途記録します。それ以外は通常授業である証拠が不足しているため「判定保留」です。判定保留の候補は自動クリック・巡回しません。
- 実際のLoiLoNote画面で、除外表示がどのDOM範囲に表示されるかは未確認です。表示が別画面・別表記の場合、この文字列検出だけでは判定できません。実機のJSONを確認するまで通常授業だけを網羅できるとは扱いません。


## 通常授業の巡回ゲート（v0.8.10）
- 巡回前に授業名を入力し、画面本文に同じ文字列が存在することを検査します。
- 「自主学習と並行した授業」ではない通常授業であることのチェックと、最終確認ダイアログへの同意を必須にしました。
- 除外フレーズが現在の画面に存在する場合は巡回を拒否します。
- 巡回JSONには入力授業名、確認方式、制約を記録します。
- これはユーザー確認と可視文字列一致による安全ゲートであり、LoiLoNoteの授業属性を自動検証するものではありません。確認できない授業は巡回しないでください。


## 授業一覧インベントリ修正（v0.8.10）
- 授業候補の抽出元を、実機DOM診断で確認された `div.courseListItem` に限定しました。入れ子のボタン、提出状態バッジ、矢印、その他のクリック可能要素を授業として数えません。
- 1行内で授業名候補が一意に特定できる場合だけラベルを確定し、複数候補・候補なしは判定保留にします。
- 行数、ユニーク授業名数、未解決行数、重複ラベル、セレクタ不一致をJSONに記録します。
- この修正は授業一覧の候補インベントリ精度を改善するもので、授業内の教材を自動取得する機能や、自主学習並行授業の内部属性を証明する機能ではありません。実機での件数照合が必要です。


## プライバシー診断の縮小（v0.8.10）
- 可視DOMの操作候補から `data-*` 属性値と `outerHTML` の生出力を削除しました。
- フォルダ巡回JSONからも `data-*` 属性値を削除しました。
- 診断に必要な可視テキスト、要素種別、クラス名、画面位置、同一オリジンのパスのみを保持します。
- これによりDOM内部属性や任意属性値がJSONへ混入する範囲を縮小します。画面に表示された個人情報が本文・スクリーンショットへ含まれる可能性は残るため、保存ファイルはローカルで管理してください。


## v0.8.10 対象授業の確認済みリスト
今回ユーザーが通常授業と確認した18件を拡張機能内の許可リストに登録しました。授業名の手入力と毎回のチェックボックス確認を廃止し、一覧から選択できます。許可リストは巡回対象の絞り込みであり、授業一覧からの自動巡回や教材本文の一括保存を実装したものではありません。


## v0.8.10 修正
- Manifest V3の `chrome.scripting.executeScript` はページ側の分離実行環境で動くため、拡張機能側の授業許可リストを `args` 経由で明示的に渡すよう修正。
- 実行対象フレームをトップフレーム（`frameIds: [0]`）に限定。
- 無効化されていた旧確認ダイアログ分岐を削除し、画面表示の案内文を実際の選択式UIに合わせて修正。
- この修正は巡回開始時の実行時エラーを修正するもので、18授業の自動巡回・教材本文の一括取得・ログイン後自動開始を追加するものではありません。
