# LoiLoNote Local Reader v0.8.11

## 目的
LoiLoNoteでユーザーが開いているページの可視情報を端末内へ保存するChrome拡張機能です。学校資料を外部送信せず、読み取り専用で扱います。

## 実装済み
- 通常授業として確認済みの18件を選択するUI
- 表示中ページの可視テキスト、見出し、リンク、画像情報、Canvas寸法等のJSON取得
- 表示範囲のスクリーンショットPNG保存
- URLごとのSHA-256変更検出と直近5版のChromeローカル履歴
- ユーザーが開始する制限付きフォルダ構成巡回（最大150ページ・深さ16）
- フォルダ巡回結果のJSON出力と未完了・警告の明示
- ローカルJSONの検索・閲覧・統合索引出力

## 現在の制約（重要）
- 18授業を一覧から自動で順番に開く機能はありません。
- Chrome起動後・ログイン後の自動開始機能はありません。
- フォルダ巡回はフォルダ構成の記録のみです。各教材を開いて本文・画像・添付ファイルを自動取得しません。
- ノート／共有ノート／提出箱／タイムラインの全件自動巡回は未実装です。
- PDFや添付ファイルの実体、カード内の手書き、数式、画像内文字、Canvasの完全保存は保証しません。
- フォルダ巡回のChrome実機検証は未完了です。画面構造やURL遷移が想定と異なる場合は安全のため停止します。
- Chromeローカルストレージには容量上限があります。JSON・PNGはダウンロード先にも保管してください。

## 対象範囲
通常授業としてユーザーが確認した18件を選択リストに登録しています。「自主学習」自体は対象外です。「自主学習と並行した授業」の明示表示を検出した場合は処理を停止します。画面表示とユーザー確認によるゲートであり、LoiLoNote内部の授業属性を自動証明するものではありません。

## 安全性・プライバシー
Cookie、認証情報、セッション情報、非表示アプリ状態を取得しません。外部通信を行いません。ユーザー開始後のフォルダ巡回ではフォルダ候補を開きますが、提出・送信・共有・編集・削除は行いません。学校資料や個人情報をGitHub等の公開場所へアップロードしないでください。学校アカウントの利用規則・学校の許可に従ってください。
